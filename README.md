# Blockchain Pi

مستكشف مستقل لبلوكتشين **Pi Network**. بيعرض البلوكات والمعاملات والعمليات والحسابات والـ Pi المقفول، مباشرة من Horizon API العام لشبكة Pi. شغال بالعربي والإنجليزي، وعلى الموبايل والكمبيوتر.

> غير تابع لـ Pi Network أو فريق Pi الأساسي.

## المميزات

- **الرئيسية:** سعر PI/USDT من OKX، وآخر بلوك، وإجمالي Pi، ومجمّع الرسوم، والرسوم، وأحدث البلوكات والمعاملات بتتحدث كل 5 ثواني.
- **البلوكات** `/blocks` و`/blocks/{رقم}`: التفاصيل ومعاملات البلوك، والتنقل للبلوك السابق والتالي.
- **المعاملات** `/txs` و`/tx/{hash}`: الحالة والرسوم والـ Memo والعمليات بالتفصيل.
- **العمليات** `/operations`: كل أنواع العمليات بوصف مفهوم.
- **الحساب** `/account/{G…}`: الرصيد، والمتاح بعد الاحتياطي، والـ Pi المقفول وميعاد فك القفل، والأرصدة، والموقّعين، وسجل العمليات والمعاملات.
- **Pi المقفول** `/locked`، و**التداولات** و**العملات** و**مجمّعات السيولة**.
- **بحث واحد:** رقم بلوك، أو هاش معاملة، أو حساب، أو رمز عملة.
- **التبديل بين الشبكة الرئيسية والتجريبية، وبين العربي والإنجليزي.**

## ليه سريع وخفيف

- الصفحات بتتبني على السيرفر، وجافاسكريبت المتصفح حوالي 103 KB مشتركة لكل الصفحات.
- **كاش مشترك على Vercel:**
  - البلوكات والمعاملات القديمة ما بتتغيرش، فبتتخزن 30 يوم.
  - البيانات الحية بتتحدث كل 4 لـ 15 ثانية.
  - كل الزوار بيستخدموا نفس الطلبات، فمش هنتخطى حد Horizon.
- مفيش قاعدة بيانات ولا مكتبات تصميم.

## النشر على Vercel

1. في Vercel: **Add New → Project**، واختار الريبو ده.
2. الإعدادات الافتراضية لـ Next.js كفاية، ومش محتاج متغيرات بيئة.
3. لو الكود على برانش غير `main`: **Settings → Git → Production Branch**، وحط اسم البرانش، أو ادمجه في `main`.

متغيرات اختيارية في `.env.example`، لو حبيت تستخدم سيرفر Horizon تاني.

## الإحصائيات (المرحلة 2)

| الصفحة | بتعرض إيه |
|---|---|
| `/stats` | المعاملات، وPi المحوّل، والحسابات الجديدة، وPi المقفول في اليوم، لآخر 30 يوم، برسومات وجدول |
| `/unlocks` | Pi اللي لسه مقفول، واللي اتفك وما اتستلمش، وكام Pi هيتفك كل شهر لـ 24 شهر |
| `/largest` | أكبر تحويلات Pi في 24 ساعة، أو 7 أيام، أو 30 يوم |
| `/wallets` | محافظ معروفة (الفريق، البورصات) وأرصدتها المباشرة، من `src/data/wallets.ts` |

بتشتغل بـ **Postgres** (Supabase مثلاً) و**مُفهرس** بيقرا Horizon ويحدّث جداول صغيرة. من غير `DATABASE_URL` باقي الموقع شغال عادي، وصفحات الإحصائيات بتقول إنها مش متفعّلة.

### التفعيل

1. **Supabase:** اعمل مشروع، وانسخ رابط الاتصال من **Connect → Transaction pooler** (البورت 6543).
2. **قاعدة البيانات:** شغّل `db/schema.sql` في SQL Editor، أو سيب المُفهرس يعمله بـ `--schema`.
3. **Vercel → Settings → Environment Variables:**
   - `DATABASE_URL` = رابط Supabase.
   - `CRON_SECRET` = أي كلمة سر طويلة.
   - `LARGE_PAYMENT_MIN` = أقل مبلغ يعتبر "تحويل كبير" (الافتراضي 10000).
4. **GitHub → Settings → Secrets and variables → Actions:** ضيف `DATABASE_URL` بنفس القيمة.
   - الـ workflow `.github/workflows/ingest.yml` بيشتغل كل 10 دقايق.
   - **أول مرة:** من تبويب Actions شغّله يدوي بـ budget = 18000 (5 ساعات) عشان يقرا كل عمليات القفل القديمة. ممكن يحتاج أكتر من مرة، وكل مرة بيكمل من مكان ما وقف.
5. Vercel Cron بيشغّل `/api/cron/ingest` مرة في اليوم كاحتياطي (الخطة المجانية مرة واحدة يومياً بس).

تشغيل المُفهرس يدوي:
```bash
DATABASE_URL=postgres://... npx tsx scripts/ingest.ts --schema --budget=240
```

### إزاي بيحسب

- **البلوكات والعمليات:** من وقت تشغيل المُفهرس ولقدام. كل صفحة من Horizon والمؤشر بتاعها بيتكتبوا في transaction واحدة، فمفيش عدّ مكرر لو حصل وقوع.
- **القفل:** بيقرا كل أرصدة Pi القابلة للاستلام من أول الشبكة. صاحب القفل هو المستلم اللي ما يقدرش يستلم غير بعد تاريخ. لما حد يستلم، العملية بتتعلّم إنها اتستلمت.
- **نسبة الفهرسة** على صفحة `/unlocks` بتوضح وصلنا لفين في التاريخ. **الأرقام مش كاملة غير لما توصل 100%.**

## لسه مش موجود

- **أغنى المحافظ:** Horizon ما بيرتبش الحسابات بالرصيد، ومحتاج نسخة كاملة من حالة الشبكة.
- **الـ Nodes:** مفيش API عام ليها.
- **محافظ الفريق والبورصات:** القايمة فاضية لحد ما نضيف عناوين مؤكدة بمصدر علني.
